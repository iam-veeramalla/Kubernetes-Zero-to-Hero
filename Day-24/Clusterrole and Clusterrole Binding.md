Clusterrole and Clusterrole Binding
======================================

* In K8s cluster role is used to provide access to clutser scoped resources to users, groups and namespaces.
* Cluster roleBinding is used to attach/bind the clutser roles to users, groups and namespaces.

Note: we can use Role in cluster level for that we don't mention the namespace in the role yaml file.
      then it will act on all the namespaces.


* WE can create roles and clutser roles in imaprative way and declarative way.
