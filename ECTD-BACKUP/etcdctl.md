💡 What is etcdctl?
---------------------
etcdctl is the command-line tool used to communicate with etcd.
Think of it as:

     🧠 etcd = Kubernetes Brain
     💬 etcdctl = Voice used to talk to the brain

🎯👉 "etcdctl is the command-line utility used to securely manage etcd, perform backups and restores,
       check cluster health, and troubleshoot Kubernetes control plane issues."

🚀 Final Takeaway
---------------------
When Kubernetes has a problem...
One of the first places experienced administrators check is : 🧠 etcd
And the first tool they use is :💬 etcdctl
Because there's a famous Kubernetes rule:

     👉 If etcd is down, Kubernetes is down. 🔥☸️
