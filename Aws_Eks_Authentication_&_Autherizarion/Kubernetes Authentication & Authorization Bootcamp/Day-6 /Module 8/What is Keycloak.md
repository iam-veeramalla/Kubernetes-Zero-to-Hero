What is Keycloak?
==================
Keycloak is another popular Identity Provider.

Compared to Dex:
| Feature                     | Dex     | Keycloak  |
| --------------------------- | ------- | --------- |
| Lightweight                 | ✅       | ❌         |
| Easy Kubernetes integration | ✅       | ✅         |
| User management UI          | ❌       | ✅         |
| MFA support                 | Limited | ✅         |
| SSO                         | Basic   | ✅         |
| Enterprise features         | Medium  | Excellent |
Many organizations choose Keycloak when they need a full Identity and Access Management (IAM) platform.
